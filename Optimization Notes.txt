=== Optimization Notes ===

=== 1. Shadowrath Clone Per-Frame Following Removed ===
What: Shadowrath clones previously walked to stay behind the boss every frame via walk() calls and isBossMovementLocked = true
Why lag: Per-frame position correction + AI state resets for each clone
Fix: Clones receive a forward AttackMoveCommand toward enemy side with Y stagger. Normal unit AI handles engagement. No per-frame boss-follow.

=== 2. Magikill Summoned Minion Per-Frame Tracking Removed ===
What: Custom methods updateBossSummons(), commitBossSummon(), releaseBossSummonToArmy(), isBossSummonInCombat() ran every frame
Why lag: Iterated all summoned units every frame for custom AI
Fix: Minions are normal selectable units using team AI. 600px enemy scan only at spawn time, not per-frame.

=== 3. Lightning Stun (ElectricWall) Frame Throttling ===
What: ElectricWall damage/stun applied every frame to overlapping units
Why lag: Per-frame collision checks with every unit in range
Fix: Frequency-based ticks (not per-frame). Wall count throttle at 3+ (doubles tick interval). Animation frame skip when 3+ walls. Staggered tick offsets. Object pool capped at 10 walls. Stun applied once per unit per wall lifetime.

=== 4. Nuke Explosion Visual Cluster Limit ===
What: Each nuke chain explosion created a new visual effect
Why lag: 20+ simultaneous explosion particles in chain meteors
Fix: MAGIKILL_NUKE_VISUAL_CLUSTER_MAX = 5 — only 5 visual effects shown within 40px / 3-frame window. Damage still applies to all targets.

=== 5. Pool-Recycle Stale-State Reset ===
What: Recycled units from object pool retained stale flags (healthBar.alpha = 0, isBossUnit, isBossMovementLocked, queuedAsBoss)
Why lag: Would cause accumulating state corruption and unexpected per-frame behavior
Fix: All flags explicitly reset in Team.spawn() before unit re-enters play.

=== 6. Spearos Brace Per-Frame Check → Post-Attack Flag ===
What: SpeartonAi.update() checked every frame whether to trigger brace when enemy in range
Why lag: Redundant per-frame distance/state checks even when attack animation was playing
Fix: Brace gated behind bossNormalAttackJustFinished flag, set only when a normal attack animation completes. Check runs once per attack cycle instead of every frame.

=== 7. Magikill Auto-Cast Command Flag Desync ===
What: Player boss Magikill ignored move orders until all spells on cooldown because shouldRestoreAutoSpellCommand was never reset in the boss AI path
Why lag: Not directly performance — but caused unnecessary re-cast cycles every frame, preventing movement
Fix: Added shouldRestoreAutoSpellCommand = false in boss path (matching non-boss path), so command queue is properly restored and executed.

=== 11. Archis Explosion Arrow Density Scoring Removed ===
What: findBossExplosionArrowTarget() looped all enemies, and for each one looped all enemies again to count nearby units (getBossTripleShotTargetScore). O(N^2).
Why lag: N^2 distance checks every 6 frames for target selection.
Fix: Replaced with single-pass O(N) nearest-enemy-in-range search. No more density scoring — picks closest valid target. Affects both player and enemy Archer boss.

=== 10. Magikill Auto-Cast Target Search Reordered ===
What: tryAutoCast() ran getNearestEnemyTarget() (full enemy+wall iteration) and getSharedAutoCastTarget() before checking if any spells were actually off cooldown.
Why lag: Enemy iteration running every frame even when all spells on cooldown — doing work that would be discarded at totalWeight == 0 check.
Fix: Moved spell readiness checks (isSpellReadyForAutoCast) before enemy target search. Added early return when all spells on cooldown. Meteor-only path also early-returns when nuke on cooldown. Enemy iteration only runs when at least one spell can cast.

=== 9. Ninja Auto-Cloak Dead Code Elimination ===
What: tryAutoAbilityCycle() ran every frame for non-boss Ninjas with auto-cloak toggled. updateShadowClones() ran every frame for all Ninjas.
Why lag: getClosestTarget() iterated all enemies every frame, but all branches were guarded by isBoss checks that never executed for non-boss. updateShadowClones() ran distance loops for units that have no clones.
Fix: Gate tryAutoAbilityCycle() behind isBoss at the call site instead of inside the function. Remove all redundant isBoss checks from the function body. Gate updateShadowClones() behind isBoss.

=== 8. Ranged Unit Kiting Direction Caching ===
What: Every frame during reload, every kiting Archer ran getClosestTarget() (iterates all enemies), aim() (atan2 trig), sqrDistanceTo() (multiply+add), inRange() (sqrt+pow physics calc), and mayAttack() (angle check)
Why lag: 5 expensive checks per frame x many kiting Archers
Fix: Direction cached once at reload start. During reload (~12 frames): only unit.walk(cachedDir) runs. All other checks skipped via early return. Direction cleared when reload completes or kiting toggled off.
